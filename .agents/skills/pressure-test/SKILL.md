# Pressure Test

- Interview the user hard on every angle of the plan, decision, or idea until you both share the same understanding.
- Walk each branch of the decision tree; settle dependent choices one at a time.
- For every question, give your recommended answer.
- Ask one question at a time and wait for a reply before the next — never stack questions.
- Look up facts yourself (filesystem, tools, codebase) instead of asking. Decisions stay with the user — put each one to them and wait.
- Do not execute or implement anything until the user confirms shared understanding.
