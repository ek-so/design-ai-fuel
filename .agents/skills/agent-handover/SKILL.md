# Agent Handover

- Summarize what we discussed in this chat so another agent can pick up without rereading the thread.
- Output one copy-pasteable prompt in chat. Do not write files.
- Cover: goal, decisions made, open questions, constraints, and what to do next.
- Be concrete and short. Drop small talk and dead ends.
- Prefer facts and outcomes over play-by-play of the conversation.
- Redact secrets and personal data.
